# Project Summary

## Overview

This project presents the design and implementation of an intelligent anomaly detection system for IoT network environments.

The system combines network simulation, traffic capture, data preprocessing and Machine Learning techniques to analyse network behaviour and identify anomalous activity in simulated IoT scenarios.

The project was developed using open-source technologies and follows a modular architecture focused on scalability, reproducibility and practical experimentation.

---

## Main Goals

The main goals of the project are:

- Simulate realistic IoT network environments
- Generate normal and anomalous traffic scenarios
- Capture and analyse network traffic
- Extract relevant traffic features
- Train Machine Learning models for anomaly detection
- Compare supervised and unsupervised approaches
- Visualize network behaviour interactively

---

## System Architecture

The project architecture is divided into several interconnected stages:

1. IoT network simulation using GNS3
2. Traffic capture with Wireshark/TShark
3. Data preprocessing in Python
4. Feature extraction and dataset generation
5. Machine Learning model training
6. Interactive visualization with Streamlit

## Simulated Scenarios

The project includes multiple simulated IoT environments:

- Domestic IoT network
- Industrial IoT network
- Normal traffic generation
- Unreachable destination anomalies
- Simulated reconnection events

These scenarios allow controlled experimentation and reproducible testing conditions.
